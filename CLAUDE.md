# FEMME by VISTORIA — Project Guide

## Structure
- index.html — main page
- css/styles.css — all styles
- js/main.js — all javascript
- images/ — all image assets

## Critical Rule
NEVER open, read, or process any image files.
Reference images only as paths in HTML/CSS e.g. url('../images/hero.jpeg')
If an image file does not exist yet, use a CSS gradient fallback.

## Branch
Always work on main branch only. Never create new branches.

## Deploy
Hosted on Netlify via GitHub. Push to main = auto deploy.
